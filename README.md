# Ocacia Employee Map

This project provides a small Flask application to manage employees and display them on an interactive Leaflet map.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the development server:
   ```bash
   python app.py
   ```
3. Open `http://localhost:5000/` in your browser.

The `/admin` page lets you add, edit and delete employees. The main page shows them on the map.
